# Publicリポジトリへのコミット

## 自動検査

- 初回セットアップで`git config core.hooksPath .githooks`を実行します。
- pre-commit Hookはステージ済み差分の形式と秘密情報を検査します。
- CIはGit履歴をGitleaksで再検査します。

## コミット前の確認

- `git diff --cached --name-status`と`git diff --cached`でコミット対象を確認します。
- 認証情報、個人情報、未公開情報、内部URL、ローカルの絶対パスを含めません。
- 記事、コード、画像、フォントを公開できる権利とライセンスを確認します。
- 新しい依存関係を追加した場合は、用途とライセンスを確認します。

自動検査の成功は、秘密情報や権利問題がないことを保証しません。
