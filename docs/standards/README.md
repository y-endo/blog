# 開発規約

変更対象に対応する規約だけを読み、実装とレビューの判断基準として使用します。

| 対象                                | 規約                                           |
| ----------------------------------- | ---------------------------------------------- |
| TypeScript、React、Next.js          | [`coding/typescript.md`](coding/typescript.md) |
| SCSS、CSS Modules、デザイントークン | [`coding/scss.md`](coding/scss.md)             |
| MDX、記事メタデータ                 | [`coding/mdx.md`](coding/mdx.md)               |
| Publicリポジトリへのコミット        | [`public-repository.md`](public-repository.md) |

規約と自動検査が矛盾する場合は、変更を進めず、規約か検査設定のどちらを直すか確認します。
